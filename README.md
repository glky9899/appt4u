# appt4u — interactive demo

A clickable demo of a booking app for studios and salons (pilates, hair, beauty, skin care), built as a mobile web app that installs to the home screen.

- **Member:** book treatments, choose to add bookings to Apple, Google or Outlook calendars, see packages, stored value and statements, skin profile and consent, aftercare tips.
- **Owner / admin:** today view, diary by therapist, room and device, members by segment, counter (record an in-store sale), reports (cash vs revenue earned, unused package value, month and year comparisons, treatment ranking), commission statements.
- **Therapist (locum):** today's sessions, check-in and complete, earnings.
- **Agent / introducer:** referral link, WhatsApp share, referrals and payouts.

All data is sample data and is stored only in the visitor's browser. There is no server or database yet.

Static files only: `index.html`, `styles.css`, `app.js`, `sw.js`, `manifest.webmanifest`, `icons/`.
